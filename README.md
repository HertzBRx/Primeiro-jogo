# Fazendinha Renascida 🌻

Jogo idle/incremental de fazendinha que roda no navegador, em um único arquivo (`index.html`).

Você herda uma fazenda abandonada e vai reconstruindo tudo aos poucos: limpa e conserta
seis áreas (sede, pomar, lago, campo de trigo, bosque e colina), sobe 10 níveis, desbloqueia
uma árvore de habilidades, transforma produtos no moinho, apiário, queijaria, tear e cozinha,
atende encomendas especiais, enfrenta as estações do ano, contrata ajudantes e explora uma mina.

## Como jogar

Abra o `index.html` no navegador. O progresso é salvo automaticamente.

- Clique rápido na fazenda para ganhar moedas (e adiantar a obra em andamento).
- Arraste para mover a câmera, ou use “Ver fazenda inteira”.
- Música e efeitos sonoros são gerados no próprio código e podem ser ligados/desligados no topo.
