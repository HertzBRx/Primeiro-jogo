# Fazendinha Renascida 🌻

Jogo idle/incremental de fazendinha que roda no navegador, em um único arquivo.

Você herda uma fazenda abandonada: clique nela para ganhar moedas e use a loja
para limpar o terreno, consertar a ponte, a estufa e o galinheiro, desbravar a
mata, plantar, criar animais e construir.

## Como jogar

Abra o arquivo `index.html` no navegador. O progresso é salvo automaticamente.
Música e efeitos sonoros são gerados no próprio código e podem ser
ligados/desligados separadamente no topo da tela.
