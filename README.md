# Fazendinha Renascida 🌻

Jogo idle/incremental de fazendinha que roda no navegador.

Você herda uma fazenda abandonada: clique nela para ganhar moedas e use a loja
para limpar o terreno, plantar, criar animais e construir.

## Como jogar

Abra o arquivo `index.html` no navegador. O progresso é salvo automaticamente.
